📅 1. RESERVATION (Reservas)

Gestiona todas las reservas del hotel. Permite consultar, listar y actualizar asignaciones de habitaciones.

Get GET

Obtiene los detalles completos de una reserva específica por su ID.

/api/v1.3/getReservation?reservationID={id}
Parámetro Tipo Requerido Descripción
Reservation ID string Sí El ID único de la reserva en Cloudbeds. Se puede obtener del listado de reservas o de un webhook.
💡 Tip: Esta operación devuelve información completa incluyendo: datos del huésped, fechas de check-in/out, habitación asignada, balance, estado de pago y notas.
Get Many GET

Obtiene múltiples reservas con opciones de filtrado por fechas y estado.

/api/v1.3/getReservations
Parámetro Tipo Requerido Descripción
Return All boolean No Si es true, devuelve todas las reservas. Si es false, usa el límite especificado.
Limit number No Número máximo de resultados a devolver (1-100). Por defecto: 50.

Campos Adicionales (Filtros)

Parámetro Tipo Descripción
Check-in Date From dateTime Filtra reservas con check-in desde esta fecha.
Check-in Date To dateTime Filtra reservas con check-in hasta esta fecha.
Status options Filtra por estado: confirmed, checked_in, checked_out, canceled, no_show
Update Room PUT

Actualiza la asignación de habitación para una reserva existente.

/api/v1.3/putReservationRoom
Parámetro Tipo Requerido Descripción
Reservation ID string Sí El ID de la reserva a modificar.
Reservation Room ID string Sí El ID de la habitación dentro de la reserva (una reserva puede tener múltiples habitaciones).
Room ID string Sí El nuevo ID de habitación física a asignar.

👤 2. GUEST (Huéspedes)

Administra la información de los huéspedes del hotel. Incluye crear, buscar, actualizar y listar huéspedes.

Create POST

Crea un nuevo huésped en el sistema.

/api/v1.3/postGuest
Parámetro Tipo Requerido Descripción
First Name string Sí Nombre del huésped.
Last Name string Sí Apellido del huésped.

Campos Adicionales

Campo Tipo Descripción
Email string Correo electrónico del huésped.
Phone string Número de teléfono.
Address string Dirección postal.
City string Ciudad.
State string Estado/Provincia.
Postal Code string Código postal.
Country string Código de país ISO 3166-1 alpha-2 (ej: US, ES, MX).
Nationality string Nacionalidad (código ISO).
Date of Birth dateTime Fecha de nacimiento.
Gender options Género: male, female, other
ID Type options Tipo de documento: passport, nationalId, driverLicense, other
ID Number string Número de documento/pasaporte.
Notes string Notas internas sobre el huésped.
Get GET

Obtiene la información de un huésped específico.

/api/v1.3/getGuest?guestID={id}
Parámetro Tipo Requerido Descripción
Guest ID string Sí El ID único del huésped.
Get Many GET

Lista todos los huéspedes del hotel.

/api/v1.3/getGuests
Parámetro Tipo Requerido Descripción
Return All boolean No Devolver todos los resultados.
Limit number No Máximo de resultados (1-100).
Search GET

Busca huéspedes por nombre, email u otros criterios.

/api/v1.3/getGuests?name={query}
Parámetro Tipo Requerido Descripción
Search Query string Sí Término de búsqueda (nombre, email, teléfono).
Update PUT

Actualiza la información de un huésped existente.

/api/v1.3/putGuest
Parámetro Tipo Requerido Descripción
Guest ID string Sí El ID del huésped a actualizar.

Los campos actualizables son los mismos que en la operación Create.

🛏️ 3. ROOM (Habitaciones)

Gestiona las habitaciones del hotel, disponibilidad, bloqueos y tipos de habitación.

Get Many GET

Lista todas las habitaciones de la propiedad.

/api/v1.3/getRooms
💡 Tip: Devuelve todas las habitaciones con su estado actual (disponible, ocupada, bloqueada, etc.)
Get Room Types GET

Obtiene todos los tipos de habitación configurados.

/api/v1.3/getRoomTypes
💡 Tip: Útil para conocer las categorías de habitaciones (Estándar, Suite, Deluxe, etc.) con sus características y precios base.
Get Available GET

Consulta disponibilidad de habitaciones para un rango de fechas.

/api/v1.3/getAvailableRoomTypes
Parámetro Tipo Requerido Descripción
Start Date dateTime Sí Fecha de inicio (check-in).
End Date dateTime Sí Fecha de fin (check-out).
Number of Rooms number Sí Cantidad de habitaciones necesarias.
Number of Adults number Sí Número de adultos.
Get Unassigned GET

Obtiene habitaciones sin asignación para un período.

/api/v1.3/getUnassignedRooms
Parámetro Tipo Requerido Descripción
Start Date dateTime Sí Fecha de inicio.
End Date dateTime Sí Fecha de fin.
Block Room POST

Bloquea una habitación para un rango de fechas (mantenimiento, fuera de servicio, etc.).

/api/v1.3/postRoomBlock
Parámetro Tipo Requerido Descripción
Room ID string Sí ID de la habitación a bloquear.
Start Date dateTime Sí Inicio del bloqueo.
End Date dateTime Sí Fin del bloqueo.
Unblock Room DELETE

Desbloquea una habitación previamente bloqueada.

/api/v1.3/deleteRoomBlock
Parámetro Tipo Requerido Descripción
Room ID string Sí ID de la habitación.
Start Date dateTime Sí Inicio del período a desbloquear.
End Date dateTime Sí Fin del período a desbloquear.

🏨 4. PROPERTY (Propiedad)

Información de la propiedad/hotel.

Get System Info GET

Obtiene información del sistema y versiones de componentes de la propiedad.

/api/v1.3/getHotels
💡 Tip: Útil para verificar la conexión y obtener el Property ID que se necesita en otras operaciones.

🧹 5. HOUSEKEEPING (Limpieza)

Gestión del estado de limpieza de habitaciones y asignaciones del personal.

Get Status GET

Obtiene el estado de limpieza actual de todas las habitaciones.

/api/v1.3/getHousekeepingStatus
💡 Tip: Devuelve una lista de habitaciones con su estado: clean, dirty, inspected.
Get Assignments GET

Obtiene las asignaciones de limpieza del personal.

/api/v1.3/getHousekeepingAssignments

Filtros Opcionales

Parámetro Tipo Descripción
Date dateTime Filtrar asignaciones por fecha específica.
Update Room Condition PUT

Actualiza el estado de limpieza de una habitación.

/api/v1.3/putRoomCondition
Parámetro Tipo Requerido Descripción
Room ID string Sí ID de la habitación.
Room Condition options Sí Nuevo estado: clean, dirty, inspected
⚠️ Nota: Cambiar a inspected indica que la habitación fue verificada por un supervisor y está lista para el check-in.

➕ 6. ADDON (Extras/Servicios Adicionales)

Gestiona los servicios adicionales que se pueden agregar a las reservas (desayuno, spa, parking, etc.).

Get Many GET

Lista todos los addons disponibles en la propiedad.

/api/v1.3/getAddons
💡 Tip: Devuelve la lista de extras configurados con sus precios y descripciones.
Add to Reservation POST

Agrega un servicio adicional a una reserva existente.

/api/v1.3/postReservationAddon
Parámetro Tipo Requerido Descripción
Reservation ID string Sí ID de la reserva.
Addon ID string Sí ID del addon a agregar.
Quantity number Sí Cantidad de addons.
Amount number Sí Precio por unidad.
Ejemplo de uso: - Addon: "Desayuno Buffet" - Quantity: 2 (dos huéspedes) - Amount: 15.00 (por persona) - Total cobrado: $30.00

Get Categories GET

/api/v1.3/getItemCategories
Add to Reservation POST

/api/v1.3/postReservationItem
Parámetro Tipo Requerido Descripción
Reservation ID string Sí ID de la reserva.

Quantity number Sí Cantidad.

🔐 9. DOOR LOCK (Cerraduras Inteligentes)

Gestiona las cerraduras inteligentes integradas con Cloudbeds. Permite crear, actualizar y eliminar llaves digitales.

⚠️ Nota: Esta funcionalidad requiere que el hotel tenga integrado un sistema de cerraduras compatible con Cloudbeds. Si usas un sistema externo como TTLock, puedes usar HTTP Request directamente.
Get Keys GET

Obtiene todas las llaves digitales de la propiedad.

/api/v1.3/getDoorLockKeys
Parámetro Tipo Requerido Descripción
Property ID string Sí ID de la propiedad.
Return All boolean No Devolver todas las llaves.
Limit number No Máximo de resultados.
Create Key POST

Crea una nueva llave digital para una habitación.

/api/v1.3/postDoorLockKey
Parámetro Tipo Requerido Descripción
Room ID string Sí ID de la habitación para la llave.
Reservation ID string No ID de la reserva asociada.
Start Time dateTime Sí Inicio de validez de la llave.
End Time dateTime Sí Fin de validez de la llave.
Flujo típico: 1. Huésped hace check-in 2. Se crea llave con Start = hora check-in, End = hora check-out 3. Se envía la llave digital al huésped por email/SMS 4. La llave se desactiva automáticamente al check-out
Update Key PUT

Actualiza una llave existente (por ejemplo, extender validez).

/api/v1.3/putDoorLockKey
Parámetro Tipo Requerido Descripción
Key ID string Sí ID de la llave a actualizar.
Delete Key DELETE

Elimina/revoca una llave digital.

/api/v1.3/deleteDoorLockKey
Parámetro Tipo Requerido Descripción
Key ID string Sí ID de la llave a eliminar.
Delete Keys (Batch) DELETE

Elimina múltiples llaves de una vez.

/api/v1.3/deleteDoorLockKeys
Parámetro Tipo Requerido Descripción
Key IDs string Sí Lista de IDs separados por coma.
Get Settings GET

Obtiene la configuración de cerraduras de la propiedad.

/api/v1.3/getDoorLockSettings
Upsert Settings PUT

Crea o actualiza la configuración de cerraduras.

/api/v1.3/putDoorLockSettings
Delete Settings DELETE

Elimina la configuración de cerraduras.

/api/v1.3/deleteDoorLockSettings

📊 10. MARKET SEGMENTATION (Segmentación de Mercado)

Gestiona grupos y segmentos de mercado para análisis de ventas y revenue management.

Get Groups GET

Lista todos los grupos de segmentación de mercado.

/api/v1.3/getMarketSegmentationGroups
Get Group GET

Obtiene un grupo específico.

/api/v1.3/getMarketSegmentationGroup
Parámetro Tipo Requerido Descripción
Group ID string Sí ID del grupo.
Create Group POST

Crea un nuevo grupo de segmentación.

/api/v1.3/postMarketSegmentationGroup
Parámetro Tipo Requerido Descripción
Name string Sí Nombre del grupo (ej: "Canal de Reserva", "Tipo de Cliente").
Update Group PUT

Actualiza un grupo existente.

Delete Group DELETE

Elimina un grupo de segmentación.

Enable/Disable Group PUT

Activa o desactiva un grupo sin eliminarlo.

Operaciones de Segmentos

Get Segments GET

Lista todos los segmentos de mercado.

/api/v1.3/getMarketSegmentationSegments
Create Segment POST

Crea un nuevo segmento dentro de un grupo.

Parámetro Tipo Requerido Descripción
Segment Name string Sí Nombre del segmento (ej: "Booking.com", "Directo Web").
Group ID string Sí Grupo al que pertenece el segmento.
Get Segment Reservations GET

Obtiene todas las reservas asociadas a un segmento.

Parámetro Tipo Requerido Descripción
Segment ID string Sí ID del segmento.
💡 Tip: Útil para reportes de revenue por canal o tipo de cliente.
Set Default Segment PUT

Establece un segmento como predeterminado para nuevas reservas.

🔗 11. INTEGRATION EVENT (Eventos de Integración)

Gestiona eventos para sincronización con sistemas externos y webhooks.

Get Many GET

Lista eventos de integración con filtros.

/api/v1.3/getIntegrationEvents

Filtros Disponibles

Campo Tipo Descripción
Event Type string Filtrar por tipo de evento.
Status options pending, processing, completed, failed
Start Date dateTime Eventos creados después de esta fecha.
End Date dateTime Eventos creados antes de esta fecha.
Create POST

Crea un nuevo evento de integración.

/api/v1.3/postIntegrationEvent
Parámetro Tipo Requerido Descripción
Event Type string Sí Tipo de evento (ej: "reservation_sync", "guest_update").
Payload json Sí Datos JSON del evento.

Campos Adicionales

Campo Tipo Descripción
Reference ID string ID de referencia externa para tracking.
Scheduled At dateTime Programar procesamiento para una fecha/hora específica.
Update PUT

Actualiza un evento de integración.

/api/v1.3/putIntegrationEvent
Retry POST

Reintenta un evento fallido.

/api/v1.3/postIntegrationEventRetry
Parámetro Tipo Requerido Descripción
Event ID string Sí ID del evento fallido a reintentar.
⚠️ Nota: Solo se pueden reintentar eventos con estado failed.
