🏨 Crear Reservaciones y Pay By Link

Guía para automatizar reservaciones con Cloudbeds en n8n | v0.3.1

📅 Reservation → Create

Recurso: reservation | Operación: create

Crea una nueva reservación en Cloudbeds con todos los datos del huésped, fechas y tipo de habitación.

Parámetros Requeridos

CampoTipoEjemploDescripción
startDateFecha2026-03-01Fecha de check-in
endDateFecha2026-03-05Fecha de check-out
guestFirstNameTextoJuanNombre del huésped
guestLastNameTextoPérezApellido del huésped
guestEmailEmailjuan@email.comCorreo electrónico
guestPhoneTexto+52 998 123 4567Teléfono del huésped
guestCountryISO 2MXCódigo país (MX, US, ES...)
guestZipTexto77500Código postal
roomTypeIdTexto12345ID del tipo de habitación
roomQuantityNúmero1Cantidad de habitaciones
adultsNúmero2Número de adultos
childrenNúmero0Número de niños
paymentMethodSeleccióncashcash, credit, ebanking, pay_pal

Parámetros Opcionales (Additional Fields)

CampoTipoDescripción
guestGenderM/F/N/AGénero del huésped
sourceIDTextoID de fuente (Booking, Expedia, etc.)
thirdPartyIdentifierTextoIdentificador del canal de reserva
estimatedArrivalTimeTextoHora estimada de llegada (14:00)
promoCodeTextoCódigo promocional
sendEmailConfirmationBooleanEnviar email de confirmación (default: true)

Respuesta

{ "success": true, "reservationID": "RES-123456", "status": "confirmed", "guestName": "Juan Pérez", "total": 4500.00 }
💡 Tip: Usa primero Room → Get Room Types para obtener los IDs de tipos de habitación.

💳 Payment → Create Pay By Link

Recurso: payment | Operación: createPayByLink

Genera un URL de pago que redirige al cliente a Stripe (o el procesador configurado en tu cuenta Cloudbeds).

Parámetros Requeridos

CampoTipoEjemploDescripción
amountNúmero4500.00Monto a cobrar - usar {{ $json.total }} del nodo anterior
reservationIdTextoRES-123456Usar {{ $json.reservationID }} del nodo anterior
💡 ¿Por qué especificar amount? Permite flexibilidad: cobrar el total, un depósito (ej: 50%), o pagos parciales. Usa {{ $json.total }} para obtener automáticamente el total de la reservación recién creada.

Parámetros Opcionales (Additional Fields)

CampoTipoDefaultDescripción
descriptionTexto-Descripción del pago
expiresAfterNúmero7Días hasta que expire (0-30)
authPaymentBooleanfalseSolo autorizar sin capturar

Respuesta

{ "success": true, "paymentLinkId": "pbl_abc123", "url": "https://pay.cloudbeds.com/link/abc123", "amount": 4500.00 }
⚠️ Procesador de pagos: El link redirige a Stripe (o tu procesador configurado). El Property ID debe estar en las credenciales.

🔄 Flujo Completo

1. Room → getAvailable → 2. Reservation → create → 3. Payment → createPayByLink (amount: $json.total) → 4. Cliente paga en Stripe
💡 En n8n: Al crear el Pay By Link, usa expresiones para obtener datos del nodo anterior:
• Amount: {{ $json.total }}
• Reservation ID: {{ $json.reservationID }}

🤖 Prompt para Agente IA

Eres un asistente de reservaciones del hotel. Tienes acceso a herramientas de Cloudbeds. HERRAMIENTAS: • Room → getAvailable: Verifica disponibilidad (startDate, endDate, adults, rooms) • Room → getRoomTypes: Lista tipos de habitación con precios • Reservation → create: Crea reservación (devuelve reservationID y total) • Payment → createPayByLink: Genera link de Stripe (amount del total anterior, reservationId) FLUJO: 1. Pregunta fechas y número de huéspedes 2. Verifica disponibilidad con getAvailable 3. Presenta opciones de habitación 4. Solicita datos: nombre, email, teléfono, país, código postal 5. Crea la reservación (guarda el total y reservationID de la respuesta) 6. Genera el link de pago usando el total de la reservación 7. Envía el link de Stripe al cliente REGLAS: - Siempre verifica disponibilidad ANTES de prometer habitaciones - Confirma todos los datos antes de crear la reservación - El amount del Pay By Link debe ser el total de la reservación creada - Responde siempre en español, amable y profesionalmente
