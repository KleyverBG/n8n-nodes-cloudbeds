Guía de Nodos Cloudbeds

Referencia de operaciones para automatizaciones hoteleras

📑 Índice de Recursos

1 Room (Habitación) 2 ops
2 Reservation (Reservación) 2 ops
3 Guest (Huésped) 2 ops
4 Housekeeping (Limpieza) 2 ops
5 Item (Artículo) 3 ops
6 Addon (Complemento) 2 ops
7 Integration Event 2 ops
8 Event (Evento) 1 op
1
Room
Gestión de habitaciones y disponibilidad
🛏️
Get Available Rooms getAvailable

Consulta las habitaciones disponibles en un rango de fechas. Usa este nodo para verificar disponibilidad antes de crear una reservación.

📋 Parámetros

  • startDate
    date Requerido
    Fecha de inicio (YYYY-MM-DD)
  • endDate
    date Requerido
    Fecha de fin (YYYY-MM-DD)
  • roomTypeID
    string Opcional
    Filtrar por tipo de habitación específico
Get Many Rooms getAll

Obtiene la lista completa de habitaciones de la propiedad con sus detalles y estado actual.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todas las habitaciones sin límite
  • limit
    number Opcional
    Número máximo de resultados
📌 Úsalo para crear un dashboard de estado de habitaciones en tiempo real.
2
Reservation
Consulta y gestión de reservaciones
📅
Get Many Reservations getAll

Obtiene una lista de reservaciones con todos sus detalles. Es el nodo más usado en automatizaciones hoteleras.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todas las reservaciones
  • limit
    number Opcional
    Límite de resultados
  • status
    select Opcional
    Estados: confirmed, checked_in, checked_out, canceled
  • checkInFrom
    date Opcional
    Fecha mínima de check-in
  • checkInTo
    date Opcional
    Fecha máxima de check-in
Update Reservation Room updateRoom

Cambia la habitación asignada a una reservación. Ideal para upgrades o cambios de última hora.

📋 Parámetros

  • reservationID
    string Requerido
    ID de la reservación a modificar
  • roomID
    string Requerido
    ID de la nueva habitación
💡 Combínalo con "Get Available Rooms" para automatizar upgrades cuando hay disponibilidad.
3
Guest
Información y datos de huéspedes
👤
Get Many Guests getAll

Obtiene la lista de huéspedes registrados. Permite filtrar por email, nombre o estado de reservación.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todos los huéspedes
  • limit
    number Opcional
    Límite de resultados
  • filters
    object Opcional
    Filtros: email, nombre, estado
Update Guest update

Actualiza los datos de un huésped existente. Solo envía los campos que deseas modificar.

📋 Parámetros

  • guestID
    string Requerido
    ID del huésped a actualizar
  • firstName
    string Opcional
    Nombre del huésped
  • lastName
    string Opcional
    Apellido del huésped
  • email
    string Opcional
    Correo electrónico
  • phone
    string Opcional
    Número de teléfono
4
Housekeeping
Estado de limpieza y asignaciones
🧹
Get Housekeeping Status getStatus

Consulta el estado de limpieza de las habitaciones. Fundamental para coordinar al equipo de housekeeping.

📋 Parámetros

  • roomID
    string Opcional
    Filtrar por habitación específica
  • status
    select Opcional
    Estados: clean, dirty, inspected, out_of_service
💡 Programa un trigger para enviar reportes diarios del estado de limpieza cada mañana.
Get Housekeeping Assignments getAssignments

Obtiene las asignaciones de limpieza por empleado. Ve qué habitaciones tiene asignadas cada camarista.

📋 Parámetros

  • date
    date Opcional
    Fecha de consulta (default: hoy)
  • employeeID
    string Opcional
    Filtrar por empleado
📌 Envía automáticamente a cada camarista su lista de habitaciones por WhatsApp cada mañana.
5
Item
Productos y cargos de minibar/tienda
📦
Get Many Items getAll

Obtiene el catálogo de productos disponibles para venta: minibar, tienda, room service, etc.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todos los artículos
  • limit
    number Opcional
    Límite de resultados
  • categoryID
    string Opcional
    Filtrar por categoría
Get Item Categories getCategories

Lista las categorías de artículos disponibles: comida, bebidas, servicios, etc.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todas las categorías
Add Item to Reservation addToReservation

Agrega un cargo de producto a una reservación. Automatiza cargos de minibar, room service, spa, etc.

📋 Parámetros

  • reservationID
    string Requerido
    ID de la reservación
  • itemID
    string Requerido
    ID del artículo a agregar
  • quantity
    number Opcional
    Cantidad (default: 1)
  • price
    number Opcional
    Precio personalizado
💡 Integra con tu sistema POS para cargar automáticamente consumos del restaurante.
6
Addon
Servicios adicionales y extras
➕
Get Many Addons getAll

Lista los servicios adicionales disponibles: desayuno, late checkout, transporte, tours, etc.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todos los addons
  • limit
    number Opcional
    Límite de resultados
Add Addon to Reservation addToReservation

Agrega un servicio adicional a una reservación existente.

📋 Parámetros

  • reservationID
    string Requerido
    ID de la reservación
  • addonID
    string Requerido
    ID del addon a agregar
  • quantity
    number Opcional
    Cantidad (default: 1)
  • date
    date Opcional
    Fecha del servicio
📌 Cuando un huésped pide desayuno por WhatsApp, agrega automáticamente el cargo a su cuenta.
7
Integration Event
Eventos para sincronización externa
🔗
Get Many Integration Events getAll

Consulta los eventos de integración registrados. Permiten sincronizar Cloudbeds con otros sistemas.

📋 Parámetros

  • returnAll
    boolean Opcional
    Retorna todos los eventos
  • limit
    number Opcional
    Límite de eventos
  • eventType
    string Opcional
    Filtrar por tipo de evento
Create Integration Event create

Crea un nuevo evento de integración para registrar acciones de sistemas externos en Cloudbeds.

📋 Parámetros

  • eventType
    string Requerido
    Tipo de evento a crear
  • eventData
    object Requerido
    Datos del evento en JSON
  • referenceID
    string Opcional
    ID de referencia externa
8
Event
Eventos del calendario de la propiedad
📆
Update Event update

Modifica un evento existente en el calendario de la propiedad.

📋 Parámetros

  • eventID
    string Requerido
    ID del evento a actualizar
  • title
    string Opcional
    Nuevo título del evento
  • description
    string Opcional
    Nueva descripción
  • startDate
    date Opcional
    Nueva fecha de inicio
  • endDate
    date Opcional
    Nueva fecha de fin
